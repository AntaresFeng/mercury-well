# 太阳系引力势阱可视化

一个单文件网页：把太阳与八大行星的引力势阱画在同一条横轴上，用来说明**为什么去水星这么难**。

打开 [index.html](index.html) 即可，无需构建、无外部依赖、不联网。
目标是任意现代浏览器（Chrome / Edge / Firefox / Safari），支持高 DPI 屏幕与触屏悬停。

## 它要回答的问题

"去水星是不是从山顶冲下、在半山腰刹停？"这个比喻抓住了"势能差 + 刹车难"，但真正的关键常被忽略：

1. 从地球去水星，是往**太阳引力势阱深处**掉。到水星轨道时速度已经很大——霍曼转移到达速度 57.5 km/s，而水星公转 47.4 km/s，相对速度约 **10.1 km/s**；
2. 水星自身势阱极浅（逃逸速度 4.25 km/s，表面势只有当地太阳势阱的 **0.39%**），**帮不上忙刹车**；
3. 所以只能靠多次引力借力先把速度磨掉，再用自带推进剂反推入轨。

页面把这三件事画出来：太阳的深井是主角，行星的小坑叠在坡上，水星那个坑小到几乎看不见。

## 物理模型

横轴为日心距离 r（AU），纵轴为势阱深度。绘图量 `d` 由两部分叠加：

**太阳项**（主角）：d☉ = 1/r，即 Φ☉ = −GM☉/r 以 1 AU 处归一。

**行星项**：对每颗行星叠加一个洛伦兹型小坑

```
d += exag · (Φ_p / Φ☉(1AU)) / (1 + q²),     q = (x − x_p) / w
Φ_p = v_esc² / 2                            （行星表面势，km²/s²）
```

- 势场可以直接叠加，所以**小坑的尾巴不做截断**，曲线处处光滑；
- 坑口半宽 `w` 取 5 倍希尔球半径的像素值，钳制在 14–64 px；
- `exag` 为「行星小坑放大」倍数，默认 ×5。

**纵向映射**：u = (d / d_max)^p，其中 `p` 是「纵向压缩」滑杆值，d_max = 1/r_min。
`p` 越小，浅坑越容易被看见；`p` = 1 时为线性刻度。

**演示动画**：按 vis-viva 计算转移轨道速度

```
v = √( GM☉ · (2/r − 1/a_T) ),    a_T = 0.6935 AU（地球→水星霍曼转移半长轴）
```

**常数**：GM☉ = 1.32712440018×10¹¹ km³/s²，1 AU = 1.495978707×10⁸ km。

## 关键数字

- 太阳势阱在地球轨道处深 **887 km²/s²**（相当于 42.1 km/s 的逃逸速度），地球自身势阱 62.6，只有 **1/14**；
- 太阳势阱在水星轨道处深 **2292 km²/s²**（67.7 km/s），水星自身势阱 9.0，只有 **1/254**；
- 霍曼直达：出发速度 22.3 km/s（比地球公转慢 7.5，即出发 v∞ ≈ 7.5 km/s）；
  到达 57.5 km/s，比水星快 **10.1 km/s**，而水星逃逸速度仅 4.25 km/s——引力捕获不可能；
- 反例：木星自身势阱是当地太阳势阱的 10.4 倍，所以巨行星能"接得住"并借力；水星接不住；
- 真实任务：信使号 6 次飞掠（1 地球 + 2 金星 + 3 水星）把入轨减速需求从 3.13 km/s 压到约 0.85 km/s；
  贝皮科伦坡 9 次飞掠，2026-11-26 入轨。

## 已知限制

- 这是**能量账的可视化**，不是轨道仿真：没有行星间的 N 体摄动、没有真实星历、没有借力飞掠的具体轨道；
- 未包含太阳光压、热环境、广义相对论（水星近日点进动 43″/百年）；
- 小坑的**宽度与深度都做了视觉夸大**，只能比较相对大小，不能读出绝对数值——每次读数的真实比值看悬停面板；
- 「小坑放大」是统一倍数，因此放大后地球的坑会比水星的显眼得多：这是真实比值的体现（7.1% 对 0.39%），不是画错了。
